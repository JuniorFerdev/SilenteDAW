# Plan de trabajo con el Manual de operaciones de Cubase Pro 15 (español)

Fuente: `/Applications/ARCHIVO FER/Cubase_Pro_15_0_Operation_Manual_es.pdf` (1713 páginas), aportado por Fer
el 31-10-2026 para su proyecto musical personal. Objetivo: que Silente se use **igual que Cubase** (misma
distribución, nombres, menús, atajos y flujos), para no reaprender. Se replica la disposición y el
comportamiento descritos; los iconos y gráficos se dibujan en Silente (sin logotipos ni recursos de Steinberg).

## Método por etapas

1. Una etapa = un capítulo (o parte de uno). Se leen solo sus páginas con el visor de PDF, incluidas las figuras.
2. Antes de programar: lista de funciones del capítulo, qué existe ya en Silente y qué falta (en `docs/MANUAL_<capitulo>.md`).
3. Se desarrolla al pie de la letra, con pruebas automáticas y captura comparada con las figuras del manual.
4. Fer revisa y decide la siguiente etapa. No se lee el manual completo de una vez (ahorro de tokens).

## Progreso

- 31-10-2026 · Etapa 1 (Ventana de proyecto): lectura y análisis hechos → `docs/MANUAL_01_VENTANA_PROYECTO.md`. Siguiente: sub-etapa 1A.
- 01-11-2026 · Etapa 1 completa (1A–1D) + comandos de teclado de Cubase. Siguiente: Reproducción y transporte.
